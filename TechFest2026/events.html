EVENTS

1. Competitive Coding Contest

A coding contest is a time-bound programming event where individuals or teams solve algorithmic or software problems and submit code for automated grading.
Focuses on data structures, math, and optimization within a set window (typically 1 to 2 hours).

What You Have To Do?

Solve atleast 5 coding problems

2. Web Design Challenge

A web design challenge is an event where participants are tasked with creating a website or web application within a specified timeframe.
It often involves designing user interfaces, implementing responsive layouts, and ensuring cross-browser compatibility.

What You Have To Do?

Create a responsive website that showcases a specific theme or product using html and css.
